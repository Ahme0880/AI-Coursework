# Cabin Price Prediction Using AI

Final project for the **Building AI course project**

## Summary

This project uses artificial intelligence to estimate cabin prices based on features such as size, sauna size, distance to water, number of bathrooms, and proximity to neighbors. The goal is to provide fast and consistent price estimates using machine learning. **Building AI course project**

## Background

Estimating property prices can be difficult because many different factors affect a property's value. This project aims to help buyers, sellers, and real estate professionals by providing AI-based price predictions.

Problems it addresses:
* Inconsistent manual price estimates
* Time-consuming property evaluations
* Human bias in pricing decisions

## How is it used?

A user enters cabin information such as size, sauna size, distance to water, number of bathrooms, and distance to neighbors. The AI model processes these inputs and predicts an estimated cabin price.

Possible users include:
* Home buyers
* Home sellers
* Real estate agents
* Property valuation companies

## Data sources and AI methods

The project uses supervised machine learning with historical cabin sales data. A neural network is trained using cabin features and their known selling prices to learn the relationship between property characteristics and market value.

## Challenges

The model's accuracy depends on the quality and quantity of the training data. Market conditions change over time, and factors such as renovations, location quality, or local demand may not be fully captured.

## What next?

Future improvements could include:
* More training data
* Location data using maps
* Images of cabins
* Better neural network architectures
* Regular model retraining with new sales data
